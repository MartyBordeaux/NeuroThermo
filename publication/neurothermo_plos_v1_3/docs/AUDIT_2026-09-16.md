# Repository audit against the 14 September 2026 manuscript draft

Audit date: 16 September 2026.

## Baseline checked

Historical release: `v1.2`, branch `publication/plos-v1.2`, commit `245791ac47af49feb9b765407831c24d0cdf6b60`.

The historical release already contains the material needed for the unchanged upstream chain:

- 50 raw current-clamp/capacitance ABF files and raw-data manifest;
- QC/provenance material and frozen manual spike selections;
- frozen accepted spiking sweeps, peak overrides, and threshold brackets;
- restricted four-parameter HR fit and frozen v3.9 result tree;
- primary endpoint/transition inputs and results;
- historical KL convergence and publication replay infrastructure;
- animal/cell provenance and the explicit two-animal-day limitation for SCA3.

These files remain authoritative and are not duplicated here.

## Gaps found relative to the revised draft

The v1.2 release predates the post-rejection analyses. It did **not** contain:

1. the final route-robustness pipeline (`neurothermo_route_robustness_v1_0_0`);
2. the final direct-current prediction pipeline (`neurothermo_current_intervention_predictions_v1_0_3`);
3. the final raw voltage-proxy sensitivity audit (`neurothermo_raw_proxy_robustness_v1_0_0`);
4. the revised manuscript source with the 2D/525-route result as the main result;
5. the compact final verdict/source tables used for the revised Results and Supporting Information.

All five gaps are filled under `publication/neurothermo_plos_v1_3/` on branch `publication/plos-v1.3`.

## Manuscript claims covered by the added material

The new source data cover the following final-draft statements:

- 32 dependent endpoint combinations and 264 retained support scenarios;
- 43.05% forward-discordance area on the ensemble coordinate grid and no reverse-discordance region on that ensemble grid;
- 525 frozen routes, including 512 random monotone routes;
- negative ensemble-median state-minus-firing separation across the random routes and deterministic route families under both aggregation orders;
- numerical-integration/density-coverage audit summaries;
- factorial/Shapley attribution used only as supporting model-space attribution;
- fixed-SCA-endpoint physical-current intervention predictions;
- mixed/limited retrospective raw-waveform support;
- strict raw-proxy robustness failures retained as negative evidence rather than used to retune targets or gates.

## Items deliberately excluded

The following exploratory analyses were performed after the manuscript draft but are not used by it and are therefore not part of the manuscript-aligned repository layer:

- Hatano–Sasa route experiment;
- RQA/Takens experimental-dynamics branch;
- direct-relaxation and capacitance-staging exploratory analyses;
- 50-pA-only relaxation audit;
- state–relaxation bridge.

Including them in the canonical release would blur the boundary between manuscript-supporting analyses and later unsuccessful exploration.

## Remaining archival gap

The public branch now contains all revision source code and the compact manuscript-facing result tables, but the three complete result ZIP archives are substantially larger than the compact tables. Their exact SHA-256 values and sizes are recorded in `FULL_RESULT_ARCHIVES.md` so a future GitHub/Zenodo release can attach them without ambiguity.

A permanent archived release/DOI for this revision is therefore still required before replacing the manuscript's final Data and Code Availability placeholder. The branch commit is a reproducible Git identifier, but it is not presented as an archival DOI.

## Experimental metadata still unresolved

No computational audit can supply historical metadata that were not recovered. The manuscript-level placeholders for the original animal-ethics approval identifier/coverage and cohort sex distribution remain unresolved and must not be guessed.
