# Recovered upstream source bundles

Seven source trees were reconstructed from immutable Git blobs on `freeze-working-code-through-v1.3.1`. Single-file `.b85` bundles are Base85-encoded zlib-compressed JSON. `.lzma85` bundles are Base85-encoded LZMA-compressed JSON; multipart bundles are concatenated before Base85 decoding. Each JSON object maps relative paths to UTF-8 source text. `RECOVERED_SOURCE_HASHES.tsv` records Git blob identities, compressed-payload SHA-256, JSON-payload SHA-256 and deterministic restored-tree SHA-256. Historical ZIP SHA-256 values from freeze manifests are retained as separate provenance because the JSON bundles use a different container. No scientific source code was modified during restoration. The exact frozen cell-fit v3.9 source is restored separately and compared against the readable main-sourced copy.
