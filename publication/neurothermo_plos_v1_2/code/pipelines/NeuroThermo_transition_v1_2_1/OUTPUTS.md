- `boundary_curve_summary_v1_2_1.csv`: equal-biological-pair ensemble boundary curves.
- `biological_pair_drive_sensitivity_surface_v1_2_1.csv`: scenario-first gradient aggregation within biological pairs.
- `drive_sensitivity_surface_v1_2_1.csv`: ensemble scenario-aware drive-sensitivity surface.
- `biological_pair_drive_sensitivity_at_boundaries_v1_2_1.csv`: within-pair weighted sensitivity summaries.
- `drive_sensitivity_at_stage_boundaries_v1_2_1.csv`: equal-pair ensemble sensitivity summaries.
- `biological_pair_legacy_path_recovery_v1_2_1.csv`: scenario-first recovery of drive-early/coupled/drive-late tracks.
- `legacy_path_recovery_summary_v1_2_1.csv`: comparison with frozen v1.1 marker medians.
- `RUN_SUMMARY.json`, `REPORT.md`, `figures/`.

Raw scenario-level values are not duplicated because the authoritative v1.2 `checkpoints/scenario_XXXX.csv.gz` remain the audit source.
