# Primary-dt diffusion-noise sensitivity

This directory archives the reviewer-facing stochastic-noise sensitivity calculation for the KL-before-firing result.

## Frozen design

- primary integration step: `dt = 0.025 ms`
- seeds: `20260818, 21260821, 22260823, 23260837, 24260855`
- cohort: 264 support scenarios / 32 biological pairs
- path grid: 31 interpolation points
- baseline diffusion: `D = (0.0025, 0.01, 0.00025)`
- tested diffusion levels: `0.5D` and `2D`
- burn-in: 2400 ms
- stationary sample: 6000 ms
- density estimator and KL marker definitions: unchanged from `NeuroThermo_KL_convergence_v1_0_1`
- per-condition reference grids: five-seed primary-dt all-extrema grids using the frozen 2% margin, with required sample retention = 1.0

The two-pass condition-specific grid construction is used only to prevent tail clipping under altered diffusion. No dt, seed, cohort, firing-stage reference, marker definition, aggregation definition, or path sampling was changed.

## Primary result

For the frozen primary marker `seed_median_curve_isotonic`, define

`Delta p = p_KL - p_firing`.

Negative values mean KL balance occurs earlier along the WT-to-SCA3 path than firing balance.

| Noise | Aggregation | xyz median Delta p | xyz frac. pairs < 0 | xy median Delta p | xy frac. pairs < 0 | z median Delta p | z frac. pairs < 0 |
|---|---|---:|---:|---:|---:|---:|---:|
| 0.5D | marker-first | -0.161718 | 0.6875 | -0.041321 | 0.59375 | -0.198684 | 0.71875 |
| 0.5D | curve-first | -0.104435 | 0.71875 | -0.161162 | 0.65625 | -0.153839 | 0.65625 |
| 2D | marker-first | -0.105721 | 0.78125 | -0.099002 | 0.75000 | -0.126297 | 0.68750 |
| 2D | curve-first | -0.147308 | 0.81250 | -0.133057 | 0.78125 | -0.149417 | 0.75000 |

Thus full-state KL-before-firing and slow-state KL-before-firing are preserved at both `0.5D` and `2D` under both aggregation orders. Minimum grid retention is exactly `1.0` in both conditions.

The descriptive slow-state-dominance criterion `Delta p_z < Delta p_xy` is preserved for both aggregation orders at `2D` and for marker-first at `0.5D`, but not for curve-first at `0.5D` (`-0.153839 > -0.161162`). Therefore the robust claim is KL-before-firing; slow-state dominance should remain descriptive rather than universal.
